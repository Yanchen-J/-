《第二班》设定集 —— 夙安公司运作手册
（写作圣经 · 内部资料 · 离职即焚）

================================================================
〇、本书定位与基调
================================================================
类型：都市异闻 + 职场经营 + 悬疑
基调：日常线轻松搞笑，用社畜的疲惫与黑色幽默打底；以此反衬真相
      揭开时的严肃与黑暗。越往后笑点越少、寒意越重，但日常吐槽
      始终是底色——读者在笑的时候被刀，效果最佳。
一句话核心：
    现实背面有一家正在亏损倒闭的"异常维护公司"，主角入职当基层
    员工，从处理一个个诡异工单做起，一路往上爬，最后发现这家公
    司本身才是最大的异常——而"现实"是它唯一的、即将流失的客户。

写作铁律（每次动笔前默念）：
    1. 超自然要"祛魅"成打工：异常有工单号、有报销流程、有甩锅。
    2. 主角用工程师思维 debug 鬼神，不靠玄学靠逻辑。
    3. 每解决一个问题都在给自己埋雷（金手指有代价）。
    4. 笑点来自"用办公室逻辑处理灵异事件"的荒诞反差。
    5. 设定不许临时乱编——查本手册，对不上就改剧情不改设定。

一、世界观：两个世界面
================================================================
【正面 · 现实】
    我们熟悉的世界。靠"规则"维持正常运转。普通人生活其中，对背
    面一无所知。

【背面 · 夙界】
    现实的"维护层"。一切诡异、灵异、说不清的现象，本质都是背面
    维护作业"溢出"到正面的副作用。
    - 夙界不是地狱也不是异世界，更像现实这台机器的"后台机房"，
      阴冷、潮湿、永远在加班的氛围。
    - 夙界的地理是"现实的废稿"：作废的街道、加载失败的楼层、被
      删掉又没删干净的地点，层层堆叠。越往深处，越是更"旧版本"
      的现实残片（此为甲方真相的伏笔）。

【两面通道】
    称"接缝"。多出现在现实中"逻辑薄弱"的地方：午夜的写字楼、没
    人走的天桥、停业的商场、报销流程的灰色地带（玩笑也是真的，
    见经费篇）。夙安员工持工牌可开接缝。

二、核心概念：什么是"异常"
================================================================
现实会自发熵增、长出 bug，称"异常"。常见类型：

  1. 规则型：一条没人记得来历、却所有人莫名遵守的规则。
     例：某小区所有人默认"不能按 13 楼电梯键"，问起来没人说得清。
  2. 地点型：本该存在却"加载失败"的地点。
     例：消失的电梯楼层、午夜多出来的公交站、写字楼第 13 层。
  3. 记忆型：集体记忆里多出或缺失一段。
     例：全城都"记得"一位从未存在的老市长。
  4. 行为型：会传染的动作或习惯。
     例：某天起，一条街的人路过某处都会无意识鞠一躬。
  5. 实体型：从裂缝渗出来、有物理形体的东西（最像传统"鬼怪"）。

【异常的行为逻辑】
    - 异常不及时处理会"扩散"：轻则局部现实崩坏，重则区域被
      "格式化"（彻底重写，连同里面的人）。
    - 异常并非全是恶意。很多只是"程序错误"，没有意识；但少数
      高阶异常有"诉求"——它们想存在下去，想被记住，想不被删除。
      （这是中后期主角能与异常谈判、结盟的伏笔，务必早埋。）
    - 异常分级：E / D / C / B / A / S。第二班日常接 E-C 级，B 级
      要立项，A 级以上归特勤组（理论上）。

三、维护机构：夙安（乙方公司）
================================================================
全称：夙安现实维护有限责任公司（夙界第七维护区承包方）
性质：背面世界的一家公司。承包"本区域现实"的维护合同。
现状：连年亏损，濒临破产。在偷偷裁员、压缩预算、KPI 造假。
      ——全书的核心张力来源：一家烂公司，维护着所有人的现实。

【组织架构（自上而下）】
  · 甲方……………………谁都没见过。签了维护合同的"客户"。最大悬念。
  · 总部 / 董事会………高层。只关心续约、KPI、成本。脸谱化的"管理派"。
  · 合规审查组…………总部鹰犬。名为审查，实为清洗知道太多的基层。
  · 各维护分部…………按区域划分。本书主舞台是"第七维护区·城东分部"。
  · 特勤组………………精英嫡系，专吃 A/S 级大单和功劳。瞧不起基层。
  · 一班…………………分部嫡系，资源好、捡软柿子、抢功一流。
  · 三班…………………外包性质，人员混杂，干最脏的活，地位最低。
  · 第二班………………【主角所在】夜班维护组。接没人愿接的烂单。
                        人少、预算少、风评差，但实战最硬、最有人味。

【第二班为什么是好舞台】
    底层视角看清整台机器的腐烂；穷，所以每一分经费都是生死；烂单
    最危险，也最容易撞见真相；五个怪人组成的小团体，是全书温度来源。

【对外身份 · 怎么跟普通人打交道（重要 · 维持祛魅）】
    铁律：普通人不知道、也不能知道"夙界""异常""维护现实"这些。
          夙安在正面世界，必须有一套能糊弄过去的官方马甲。
    马甲：对外统一挂靠一个含糊的、没人说得清具体归属的官方名头——
          【市·特殊环境安全评估中心】（视场景也用"应急事件复核组"
          "危房与公共安全勘察"等等子马甲）。工牌、介绍信、鉴定章
          一应俱全，看着正规，却查不到上级是谁。
    话术：永远是"排查隐患、评估风险、出具安全意见"。把灵异，翻译成
          普通人能接受的词——
            异常致人失常 → "疑似有毒有害气体 / 环境致幻 / 群体性癔症"
            处置异常     → "环境检测、隐患排查、危房复核"
            结单报告     → 给普通人的版本是一纸"安全评估意见书"
          （这正是"灵异祛魅成打工"的延伸：连对外公关，都走流程。）
    派单链路：普通人撞见怪事 → 报到街道办 / 物业上级 / 110 等寻常
          渠道 → 这些渠道里埋着极少数"对接人"（多半自己也只当夙安是
          某个特殊部门），把单子悄悄转进夙界系统 → 第二班的派单机
          才"滋啦"地响。所以报案的普通人，是被动等来一支"官方检测
          队"，绝不知道来的是"管鬼的"。
    铁则：在普通人面前，林栎那双校验的眼睛、小满进记忆的本事、封条、
          工时——一律不露。能用普通话术糊弄过去的，绝不露底。露一次，
          就是合规审查组找上门的把柄。

================================================================
四、金手指：「校验」（差异化关键）
================================================================
主角林栎的能力，叫【校验】。

【核心机制】
    他能临时把一条异常规则"改写"成对自己有利的版本。
    但改写有三条硬约束，永不放宽：

  约束一 · 守恒
    改写不能凭空消除异常，只能"转移"。把麻烦从 A 挪到 B，
    B 迟早要还。——杜绝"一键解决"，逼出权衡。

  约束二 · 反噬锁定
    每改写一条规则，这条规则会"优先锁定他本人"。
    他因此成了规则世界里最显眼的目标。——爽点变成刀尖交易。

  约束三 · 额度（工时）
    能力有"工时"上限。超额使用会透支自己的"存在"，
    有被现实当成 bug 删除的风险。——透支线贯穿全书，揪心。

【成长路线（与剧情台阶严格绑定，禁止跳级）】
    第1-2卷：改写"单条规则"。
    第3卷：  改写"规则之间的关系"（让两条规则互相抵消）。
    第4-5卷：改写"机构的作业流程本身"。
    第6卷：  改写"合同条款"——终极进化，终局靠谈判而非武力。

【写作注意】
    每次用校验，必须明写代价：转移到哪了？锁定了什么？花了多少
    工时？代价是悬念燃料，不许省略。

================================================================
五、经费 / 工时：本书的"生死货币"
================================================================
这是本书最大的差异化卖点之一：决定谁生谁死的不是战力，是预算。

  · 工时：员工执行维护、使用能力的"燃料"，也是寿命/存在的抵押物。
  · 经费：处理异常需要耗材、增援、开接缝，全要钱。没预算就裸上。
  · 报销：流程繁琐到荒诞。一张报销单能卡死一条人命（喜剧+恐怖）。
  · 苗姐：第二班会计，管经费与工时。全公司最可怕的人——因为她
          签的字才真正决定谁能活着回来。

【核心维护耗材 ·「封条」】（替代旧设定"圣盐"，给出自洽根据）
  原理：现实靠"记录与确认"维持。一段现实之所以正常，是因为它被
        系统"确认"为正常、被记录在案。异常＝一段现实的记录出了错、
        失去确认、开始失控扩散。
        「封条」是一种印着工单号与权限码的官方制式符签。维护员把它
        贴在异常的"接缝/核心"上，注入工时激活后，等于强行往这段
        出错的现实上，打一个系统级标记——【此处已由夙安接管 ·
        暂停扩散 · 待结案】。异常"认"这个权限标记，会被暂时冻结、
        止住蔓延。它不"消灭"异常（消灭要靠校验/对症处置），只
        "封存"，争取时间。——这是"用办公室逻辑处理灵异"的器物化：
        不是撒盐辟邪，是给失控的bug，盖一个"已锁定"的章。

  贵：制式封条有防伪权限码、需注入工时激活、单价不菲（80元/张档位）。
      工时本就是员工的命，激活封条＝拿自己的"存在"垫一点进去。

  抠门平替（保留的喜剧梗）：苗姐常驳回制式封条，逼员工用——文具店
      买的普通"封条"贴纸 / 淘宝9块9一百张的"已封存"标签 / 实在不行
      自己拿打印机打。没有官方权限码，只能靠维护员那点微末权限"手动
      激活"，效率低、易脱落、撑不久，但便宜到苗姐肯签。
      桥段范例（基调示范）：林栎想领一张制式封条封一个C级接缝，苗姐
      说预算超了，给他批了"淘宝同款封存贴，凭订单截图报销，单次上限
      20元"。林栎蹲在异常面前，往接缝上贴9毛9一张的塑料贴纸，还得
      用手指头戳着它、把工时一点点抠进去激活。——这就是本书的味道。

  注：盐、镜子、红线、粉笔等仍可作为辅助小道具（划界、照影、临时
      压制），但"决定性的封存/接管"，靠的是封条这套权限逻辑，
      而非民俗辟邪。耗材体系自此以"记录/权限/工时"为根，不靠玄学。

六、核心人物
================================================================
【主角 · 林栎】
    名校毕业、海投无果的应届生（贴近目标读者）。误打误撞入职夙安
    第二班。性格：不信邪、爱较真、社畜式疲惫 + 黑色幽默。
    情绪类型——【内耗型】（重要·写作时务必守住）：气、屈、怕，都不
    往外发，全往肚子里咽，再一遍遍在心里反刍、磨自己。极少外放（吼、
    砸、动手），真要写他动了一下，必是"连他自己都吓一跳、很少这样"，
    用来反衬这事钻得有多深。他消化情绪的出口是两样：黑色幽默（耍贫、
    自嘲），和"越慌/越气越要算"——把翻涌的情绪，逼成一条条冷静的
    推断。愤怒越大，他往往越安静、越往里走。脏话可有，但多是从牙缝
    低低挤出、且常是冲自己，不是冲人吼。
    最大特质：用工程师思维拆解超自然——别人当鬼神，他当系统故障
    debug。口头禅类："这不就是个边界条件没处理好嘛。"

【班长 · 老周】
    第二班实际负责人。资深维护员，知道很多内幕但讳莫如深。亦师亦
    友。过去与"上一任能力者"（叛逃者）深度绑定——中期重大反转源。

【小满】
    负责"记忆型异常"。能进出别人记忆，但自己的记忆是一片空白。
    （她是谁、记忆去哪了，是贯穿到第六卷的伏笔。）

【大鹏】
    力量型，专治"实体型异常"。头脑简单、忠诚。喜剧担当 + 工具人
    保命符。第四卷候选牺牲对象之一（制造真正的痛感）。

【会计 · 苗姐】
    管报销与工时。全公司最可怕的人。冷面、抠门、原则性极强，但
    关键时刻会"违规批一次预算"救人——刀子嘴的温度。

【对立面（分层，逐卷升级）】
    早期：失控的异常 + 抢单的其他班组（内部竞争）。
    中期：公司高层、为 KPI 牺牲基层的管理派、合规审查组。
    后期：神秘"甲方"，及揭示真相后真正的敌人。

【叛逃者 · 旧能力者（暂名 商陆）】
    老周的旧搭档，上一任「校验」持有者。被认为殉职，实则叛逃。
    主张"公司本身才是问题"。亦敌亦友，是主角的镜子与引路人。

七、分卷结构（6 卷 · 约 300 万字）
================================================================
第一卷《试用期》（约40万）：立人设/规则/金手指，单元怪谈开局。
    卷末钩：处理过的几个异常指向同一"源头"——是被人为投放的。
第二卷《转正》（约45万）：扩舞台，引入内部竞争与"经费即生死"。
    卷末转：上一任能力者不是殉职，是叛逃了。
第三卷《项目制》（约50万）：升级到"立项"，主角能改写流程，格局抬升。
    卷末高潮：公司故意制造异常再修复，向甲方造假证明价值。
第四卷《合规审查》（约55万）：最黑暗一卷，主角与体制正面冲突，
    牺牲一名核心同事。卷末：主角被打成"异常"，遭全公司通缉。
第五卷《破产清算》（约55万）：公司崩溃，甲方启动"清算"（格式化重来）。
    揭核心真相：甲方=上一个被格式化现实的残余意志，想重启自己。
    卷末：主角想出"重写合同"而非"打赢甲方"的路。
第六卷《续约》（约55万）：终局。能力进化到改写合同条款。
    终极博弈是一场"现实该由谁、按什么规则维护"的谈判/重构。
    结局：现实维护从垄断乙方变成透明、人人可参与的新系统。

九、反烂尾设计（规则怪谈老大难）
================================================================
    1. 甲方早定：第五卷揭晓的"甲方=上一个被格式化现实的残余意志"，
       从第一卷就埋线（消失的地点其实是上个现实的残片）。
    2. 不靠高维文明兜底：真相落在"体制/合同/维护权"等社会命题上，
       而非"其实是外星人/游戏副本"。逼格更高也更稳。
    3. 能力升级与剧情绑定：金手指不会突然变神，每级进化对应一个
       剧情台阶，杜绝"为了赢硬开挂"。
    4. 主题闭环：开篇"找不到工作的社畜"，结尾"重构整个维护系统"——
       个人成长与世界格局同频收尾。

十一、爽点节奏（写作时对照）
================================================================
    短爽点（每1-3章）：解一个工单 / 一次校验妙用 / 怼上司抢单成功。
    中爽点（每卷2-3次）：晋升 / 扳倒对手 / 解开一层真相。
    大爽点（每卷末）：格局跃升 + 重大反转。
    代价钩：每次大爽点后加重"反噬/透支"，爽而不腻。
